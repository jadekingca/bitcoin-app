Bitcoin Power Law Workbench

A power-law model with a logarithmic price axis and linear calendar axis, inspired by Bitcoin Power Law Bands and Santostasi/Porkopolis fair-value models. Values are model estimates, not financial advice.

Model

Defaults a = 1.6e-17, b = 5.77 are a fixed workbench preset, not a verified current Porkopolis fit. Earlier cited values a = 1.42e-17, b = 5.79 differ. No automatic regression is performed.

Projection

January 1, 00:00 UTC of each year. P = a × t^b; t is elapsed days since January 3, 2009 UTC (minimum 1).

Sources

The referenced TradingView script describes a log10 regression corridor with deep value, value, hot, and mania zones. Coin Metrics supplies older daily USD reference prices; Coinbase daily closes update recent history, with Kraken and CoinGecko fallbacks. Reference prices and CoinGecko samples are not exchange candle closes. Only completed UTC days are cached. Live spot is appended at its timestamp; genuine missing days remain visible.

Data: Coin Metrics, Coinbase, Kraken. References: TradingView script, Forbes overview, CoinCodex historical prices.
